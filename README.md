# 🛒 RKWI E-Commerce Data Analysis & Strategy

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://www.python.org/)
[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange.svg)](https://jupyter.org/)
[![Pandas](https://img.shields.io/badge/Pandas-Data%20Analysis-150458.svg)](https://pandas.pydata.org/)

An end-to-end data engineering, profiling, and exploratory data analysis (EDA) pipeline designed to address catalog discrepancies, reduce stock-out risks, and optimize inventory for RKWI E-Commerce.

---

## 📌 Executive Summary
Analyzing over **10,000 product catalog entries** and **50,000 sales transactions**, this project delivers actionable inventory insights, automated exploratory reporting, and a prioritized restock schedule to maximize revenue conversion.

---

## 🚀 Key Deliverables & Main Notebook
- 📓 **[Main Analysis & Strategy Notebook](./rkwi_ecommerce_eda_and_strategy.ipynb)**: Complete end-to-end workflow covering data ingestion, catalog cross-matching, missing value imputation, EDA visualizations, and strategic business takeaways.
- 📊 **Automated Profiling Reports**:
  - [Sweetviz Report](./sweetviz_eda_report.html)
  - [YData Profiling Report](./ydata_eda_report.html)
- 📋 **[Priority Restock List](./rkwi_priority_restock_list.csv)**: Actionable inventory matrix highlighting high-demand items near safety-stock thresholds.

---

## 🛠️ Tech Stack & Methods
- **Languages & Frameworks:** Python, Jupyter Notebook
- **Data Manipulation:** `pandas`, `numpy`
- **Visualization:** `matplotlib`, `seaborn`, `sweetviz`, `ydata-profiling`
- **Web Scraping & Matching:** Live Amazon comparison data (`scraped_rkwi_amazon_live.csv`)

---

## 💡 Key Business Insights
1. **Catalog Alignment:** Cross-referenced 10k product listings against live e-commerce benchmarks to resolve listing discrepancies.
2. **Restock Optimization:** Identified top stock-out triggers across product categories, establishing a automated restock cadence.
3. **Transaction Trends:** Profiled 50,000 July 2026 transactions to uncover customer spending behavior and peak purchasing windows.
